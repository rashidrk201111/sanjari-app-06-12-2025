## 🔐 Security Features

✅ **Row Level Security (RLS)** - Enabled on all tables
- Users can only access their own data
- Admins can access everything
- Public can view products, pricing, FAQs, approved reviews

✅ **Password Security**
- Bcrypt hashing (automatic by Supabase)
- Minimum 6 characters
- Secure reset via email

✅ **Role-Based Access**
- User role - Limited access
- Staff role - Moderate access
- Admin role - Full access

## 🔐 Security Alert

### ⚠️ Service Role Key

Earlier you shared a **service_role key**. This is dangerous!

**Action Required:**
1. Go to: https://supabase.com/dashboard/project/hgxhdmcqrcsjsxuaeyrl/settings/api
2. Find "service_role" key
3. Click "Reset" or "Rotate"
4. This invalidates the old key

**Why?**
- Service role bypasses ALL security
- Has unrestricted database access
- Should NEVER be in frontend code
- Only use in backend/server code

### ✅ Safe Keys (Already Configured)

- Anon/public key is safe ✅
- It respects Row Level Security ✅
- Already configured in `/lib/supabase.ts` ✅
